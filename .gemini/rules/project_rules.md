# 一騎当千 プロジェクト固有開発規約

本プロジェクトの開発では、以下のルールを常に遵守すること。

## 1. 言語および文体
- 回答および計画策定はすべて日本語で行うこと
- ソースコード内のコメントは日本語で、だ・である調で記述すること
- コメントには通常句点（。）を使用しないこと

## 2. ファイル冒頭のヘッダーコメント規約
すべてのソースコードファイル（新規作成・既存改修を問わず）の最上行に、以下のフォーマットでヘッダーコメントを維持すること。

```gdscript
# ==================================================
# ファイル名: <ファイル名>
# 概要: <ファイルの役割と責務を簡潔に記述する（だ・である調、通常句点なし）>
# ==================================================
```
